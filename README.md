# 🎬 MovieFlix – API de Catálogo de Filmes
Projeto Java com **Spring Boot** para desenvolvimento de uma **API REST** responsável pelo gerenciamento de um catálogo de filmes.
Inclui autenticação com **JWT**, persistência com **Spring Data JPA**, documentação via **Swagger**, e muito mais.

---

## 🚀🚀 Tecnologias Utilizadas

**Backend**
- Java 17
- Spring Boot 3
- Spring Web
- Spring Security
- JWT (JSON Web Token)
- Spring Data JPA
- Bean Validation

**Banco de Dados**
- H2
- PostgreSQL(Futuramente)

**Produtividade**
- Lombok
- Tratamento Global de Exceções

**Documentação**
- OpenAPI / Swagger

---

## 📁 Descrição do Projeto

O MovieFlix é uma API REST que permite:
- Cadastro de filmes
- Consulta paginada e filtrada
- Atualização e remoção
- Associação com categorias
- Autenticação e autorização com JWT
- Documentação pública pelo Swagger

A API é estruturada seguindo princípios de **arquitetura limpa**, utilizando **DTOs**, **services**, **repositories**, e **exception handlers** personalizados.

---

## 🔐 Autenticação

A API utiliza Spring Security + JWT, fornecendo:
- Endpoint de login
- Geração de token JWT
- Proteção de rotas privadas
- Permissões por perfil ou role
